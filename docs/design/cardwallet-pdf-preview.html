PDF preview screen on iOS and Android: sheets of the exported PDF in a pager, the layout options sheet (transparent glass), the more menu, loading, exporting, exported and the empty and error states.

  • What it is: a live preview of the sheets of the PDF (not the rendered file): one pager page per sheet, drawn with the current layout options. Opened from the PDF export menu (preview) and from the scanner activity (there the main action is Save).
  • Bars: native top bar and bottom toolbar. Top bar: close, "PDF preview" with the layout summary as subtitle, the black and white toggle (a state, so it is always visible), one more menu (share, open in another app, print on Android). Bottom: the layout button (opens the options sheet), and the main action Export at the trailing end: a prominent button on iOS, an extended FAB on Android with the layout button as the small tonal FAB 12 to its left. This is not an edit mode, so Android keeps its FAB.
  • Sheet: white paper in both themes, 6 radius like the page edit screen, level 1 shadow on iOS and a 1 outline on Android, neighbors peek 16 with an 8 gap. Paper size, orientation, pages per sheet and margins are drawn to scale (margin in points, scaled with the sheet width), so what is seen is what is exported. Full paper = the page itself, no margin.
  • Options sheet: the transparent glass sheet of the page edit screen (no dim, forced dark, grabber, half and large detents, on-glass roles). Changes apply live, nothing to confirm, Reset puts the defaults back. With the Full paper size, orientation, pages per sheet and margins are disabled with a helper line. The OCR switch only exists when a page has detected text. Image quality, password and folder are not here: the last row opens the export settings.
  • Loading: rendering sheets is non-blocking: a linear progress under the top bar, skeleton sheets, Export disabled. Exporting, opening, sharing and printing are blocking: the centered card with a 32% dim. Done: a snackbar (Android) or toast (iOS) with Open; the counter hides while it shows.
  • Empty and error: icon, title, one line, one prominent action. Empty has Close; error has Retry and a text Close. The toolbar is hidden in both.
